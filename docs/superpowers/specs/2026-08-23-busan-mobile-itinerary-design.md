# 釜山手機行程頁設計規格

## 目標

把既有 Excel 行程整理成朋友能直接用手機開啟的單頁網站。此階段只產生本機預覽，不部署。

## 技術與結構

- 純 HTML、CSS、JavaScript，不使用 React 或外部框架。
- 行程資料集中在 `js/data.mjs`，畫面與資料分離，方便後續改時間與地點。
- 以 390px 手機寬度優先設計，同時能延伸到桌面瀏覽器。
- 互動包含日期切換、複製韓文地址、Kakao Map 與 Google Maps 連結。

## 內容規則

- 日期為 2026/8/30–2026/9/5。
- 住宿：Gwangan KCC Switzen Harbor View，부산 수영구 민락수변로 49。
- 9/5 起飛時間顯示 10:00。
- 9/1 天空膠囊列車為已購票固定預約，完整顯示 09:30–10:00，其他行程不得覆蓋或改動此時段。
- 午餐與晚餐依實際用餐時間插入每日時間軸，並以不同色彩標籤辨識。
- 只有一間餐廳時直接顯示；多間餐廳時預設收合，展開後每間皆有獨立地址與地圖操作。
- 不顯示停車資訊。
- 每日補充節奏、拍照時機與雨天備案，但不擅自移除 Excel 內的景點。

## 視覺方向

採「海風旅行手帳」：深海藍底、晨光珊瑚橘與沙色卡片，使用大字級、明確時間軸與充足留白。首頁先看到旅程日期、住宿與今日主題，日期列可橫向滑動。

## 驗收

- 手機畫面無水平溢出，主要文字不小於 15px。
- 所有地點按鈕可操作，複製內容為韓文地址。
- Kakao 與 Google 連結皆以該地點韓文名稱／地址搜尋。
- 日期切換會更新標題、行程、午餐、晚餐、拍照提示與雨天備案。
